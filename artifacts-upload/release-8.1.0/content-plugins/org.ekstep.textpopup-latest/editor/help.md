**Text Popup plugin**

Text Popup will add a icon and Popup box .Enter the text required to be shown on PopUp on clicking the icon.

---

***Background Color***

Set background color of your choice for Popup box using the color picker.

***Font Color***

Set font color of your choice using the color picker. 

***Font Size***

Set font size of the text in the Popup box of your choice. 

---

***Pro tip***

Place the Text Popup button where ever you want to place in the stage and resize the Popup box if needed.
