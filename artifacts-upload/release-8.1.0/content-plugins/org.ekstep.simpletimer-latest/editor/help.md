**Content Editor Help**

***Timer plugin***

Using this plugin you can add a timer on the stage which will be persistent across question set and stages.

---
***Name***

Assign a name for this timer. When using the timer acorss multiple stages, ensure that all the timers share the same name. 

***Unit***

Set the unit for the timer. Seconds or Minutes. 

***Time***

Enter the countdown time. This is in the unit specified in the above field.

***AlertTime***

Time at which the timer should start blinking to indicate that timer is nearing the end. Ensure this value is less than 'Time'. 

***Type***

The type of timer. Should the timer countdown or count up.
